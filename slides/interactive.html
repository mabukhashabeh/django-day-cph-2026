When this is the wrong tool.

A common topic becomes valuable when you know when not to use it.

The test suite. Coverage. A missing GitHub secret. Anything that needs a database or the network — that is CI config, not a commit hook.
mypy on the whole tree, every commit — pre-push or CI. The gate people wait for is the gate people skip.

One rule about AI review

Code is arriving faster. Models write it. They are fluent. They are not embarrassed. The gate got more necessary, not less.

Deterministic checks can block a commit. Probabilistic reviewers can only advise.
