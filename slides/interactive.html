Not every hook is equal.

PEM only. Not AWS. Not a PAT. Not SECRET_KEY.

        

        
The two Django hooks need pass_filenames: false and always_run: true.

leave these off the commit

        
When not to use pre-commit.

        
Green on the machine, red in CI is two stories. A missing GitHub secret is CI config. A leftover breakpoint() is the same file.

        

          
pytest · coverage · database · network
→
CI. Same as failed tests.

          
mypy on the whole tree, every commit
→
pre-push, or CI. Slow gates get skipped.

          
ten hooks on Monday
→
hygiene first. Then one app.

          
detect-private-key as your secrets program
→
PEM only. CI is still required.
